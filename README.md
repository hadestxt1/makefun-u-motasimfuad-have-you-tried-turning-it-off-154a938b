## Run it

```sh
python3 main.py
```

The program writes its single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Model-free, deterministic, standard library only — two runs produce byte-identical output.

The line itself is 146 characters: short enough to survive the gate, long enough to land the joke.
